N10-009 Study Notes: Network Implementation

Part two of five. Domain 1 covered the conceptual foundation — addressing, routing, how packets move. Domain 2, Network Implementation, is where that theory meets physical and virtual infrastructure: how networks are actually built, what the gear does, and how the pieces connect. It's weighted at 19% of the N10-009 exam.

Ethernet and Switching

Ethernet is the dominant wired networking standard. At the physical layer it defines how signals travel over copper or fiber. At the data link layer it defines how devices are addressed and how frames are structured. Every device on an Ethernet network has a MAC address — a 48-bit hardware identifier burned into the network interface, written as six pairs of hex digits. MAC addresses are Layer 2; IP addresses are Layer 3. A switch works at Layer 2 and uses MAC addresses to decide where to send frames.

When a frame arrives on a switch port, the switch reads the source MAC address and records which port it came from in its MAC address table (also called the CAM table). When it sees a frame destined for a MAC address it already knows, it forwards the frame only to that port. When it sees an unknown destination, it floods the frame to all ports except the one it arrived on. This is how a switch reduces unnecessary traffic compared to a hub, which always floods everything to everyone.

VLANs

A VLAN — Virtual Local Area Network — is a logical subdivision of a physical network. VLANs let you isolate groups of devices on the same physical switch as if they were on entirely separate switches. Devices in different VLANs cannot communicate directly — all inter-VLAN traffic must be routed, which means it has to pass through a Layer 3 device (a router or a Layer 3 switch).

Switch ports operate in one of two modes. An access port belongs to a single VLAN and connects to end devices — a workstation, a server, an access point. The device plugged into an access port doesn't know or care about VLANs; the switch handles the tagging. A trunk port carries traffic for multiple VLANs simultaneously and is used for uplinks between switches, or between a switch and a router. Trunk ports use 802.1Q tagging — a 4-byte tag inserted into the Ethernet frame that identifies which VLAN the frame belongs to.

Spanning Tree Protocol

Redundant physical connections between switches are desirable for resilience, but they create a problem: broadcast loops. A broadcast frame entering a loop of switches circulates forever, multiplying with each pass and consuming all available bandwidth — a broadcast storm. Spanning Tree Protocol (STP) prevents this by detecting loops and blocking redundant paths, leaving only one active path between any two network segments. If the active path fails, STP recalculates and activates a previously blocked path, restoring connectivity.

Rapid STP (RSTP, 802.1w) is the modern version — it converges in seconds rather than the 30–50 seconds the original STP required. Most switches run RSTP by default. Know that STP exists, what problem it solves, and what a root bridge is (the switch that STP elects as the reference point for the spanning tree topology).

The 2.4 GHz band has longer range and better wall penetration but is heavily congested — only three non-overlapping channels (1, 6, 11) and shared with microwaves, Bluetooth, and baby monitors. The 5 GHz band offers more channels, less interference, and higher throughput but shorter range. 802.11ax adds the 6 GHz band specifically to escape congestion.

Wireless security protocols: WEP is broken and should never be used. WPA was a stopgap. WPA2 (using AES-CCMP) is the minimum acceptable standard. WPA3 is current and adds features like Simultaneous Authentication of Equals (SAE), which resists offline dictionary attacks against the handshake.

WAN Technologies

WAN technologies connect geographically separated networks. The exam covers several at a conceptual level. DSL (Digital Subscriber Line) runs over existing telephone copper. Cable broadband runs over coaxial. Fiber delivers the highest throughput and lowest latency. Cellular (4G LTE, 5G) provides connectivity where wired access isn't available, at the cost of higher latency and variable throughput. Satellite (including LEO services) covers remote locations but introduces meaningful latency due to orbital distance.

MPLS (Multiprotocol Label Switching) is worth knowing — it's a WAN technology used by enterprises and service providers that routes traffic using short path labels rather than IP addresses, improving speed and enabling traffic engineering. SD-WAN (Software-Defined WAN) abstracts WAN connectivity into software, allowing organizations to use multiple cheaper internet connections with intelligent traffic routing rather than expensive dedicated MPLS circuits.

Cloud and Virtualization Networking

Network+ expects familiarity with cloud networking concepts. The three service models: IaaS (Infrastructure as a Service) — you manage VMs and networking. PaaS (Platform as a Service) — you manage applications, the provider manages the platform. SaaS (Software as a Service) — you use the software, the provider manages everything underneath.

Virtualization networking introduces concepts that map directly to physical networking. A virtual switch (vSwitch) connects VMs inside a hypervisor the same way a physical switch connects devices. A VM can be on a separate virtual network from its host, or bridged directly to the physical network. Network segmentation through virtualization follows the same principles as physical VLAN segmentation — isolation is enforced at the software layer rather than the hardware layer.

In the Lab

The switching layer here is a Netgear GS308E — an 8-port managed switch with 802.1Q VLAN support. It's where VLAN segmentation actually happens in the lab. Port 8 is configured as a trunk port carrying both VLAN 1 (the main 10.10.10.0/24 LAN) and VLAN 20 (10.10.20.0/24, isolated lab and IoT) as tagged traffic to OPNsense's vtnet2 interface. Port 6 is the main LAN uplink. Port 1 is an access port for VLAN 20 — devices plugged in there land on the isolated network without any awareness that VLANs exist.

Inter-VLAN routing happens in OPNsense. Traffic from a VLAN 20 device heading to a VLAN 1 resource has to pass through the gateway at 10.10.10.1, which can apply firewall rules to it in transit. That's the point of segmentation — not just organization, but control over what can reach what. A device on VLAN 20 can't directly communicate with a device on VLAN 1 without OPNsense permitting it. Physical isolation without needing physical separation.

Proxmox itself is a virtualization platform that implements its own virtual networking. Each node has a Linux bridge — vmbr0 — that functions as a virtual switch connecting VMs and LXCs on that node to the physical network interface. LXCs are assigned to that bridge and appear on the 10.10.10.0/24 network as if they were physical machines. The Prometheus container running inside the Docker LXC on Shasta, the peaNUT LXC on Ankhh, the Ansible LXC also on Shasta — all of them participate in the same Layer 2 domain through that bridge, and are reachable by IP from anywhere else on the subnet.

The WAN technology in use here is a standard cable broadband connection. OPNsense sits behind the ISP router with no double NAT — the ISP router is in bridge mode, making OPNsense the true network edge. Cloudflare DDNS tracks the public IP and updates DNS records automatically when it changes, which is exactly the problem SD-WAN solves at enterprise scale: making connectivity stable and manageable regardless of what the underlying circuits are doing.

The STP note is worth making explicit: the lab doesn't have redundant switch paths right now, so STP isn't actively in play. But understanding why it exists — and what happens without it if you add a cable that creates a loop — is the kind of thing that saves you from a broadcast storm during a late-night cable shuffle. The Netgear GS308E supports loop prevention; it's enabled.
