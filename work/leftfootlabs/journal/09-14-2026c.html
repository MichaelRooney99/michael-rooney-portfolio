The Route Not Forgotten

Narrowing the faceplate feature down to something real and buildable meant an actual first piece of it could get built: the schema and data layer underneath it — real device and shelf width fields, a new table for keystone jacks, a real spacing constant. The interesting part wasn't the schema itself. It was a small decision made specifically because of something that went wrong a few days earlier.

A gap that had a name this time

The shelf data layer, built days before this, shipped with real tests and real working logic — and no route exposing it over HTTP at all, a gap that stayed invisible until the frontend became the first thing that actually needed it. This time, the route for the new keystone table got written in the same pass as the table itself, not added later once something else needed it. The comment in the code says so directly: added now, not discovered missing later, because that was the whole point of having found the gap the first time.

Every new column, checked against a real existing database

Three real migration guards went in alongside the new columns — one for each new field, checking whether an existing local database already has the table from before the field existed, and adding it in place if not. That pattern already existed in this project; what's worth noting is that it got applied automatically this time, without needing to be reminded, because skipping it once already caused a real, confusing mismatch between what a column was named and what it actually held.

Verified against more than a fresh database, too: a simulated pre-existing one, with a real row already sitting in it from before the new column existed, confirmed the value actually gets backfilled rather than left blank. A migration that only works on a database that's never seen production data isn't actually a real migration yet.

What actually shipped

Real device and shelf width fields, a new keystone table and its route, a real 8mm spacing constant — all additive, all verified against a fresh seed and a simulated existing database both, fifty-four tests passing where forty-seven did the session before. Small in scope, but the kind of small that comes from actually remembering the last mistake instead of just moving past it.
